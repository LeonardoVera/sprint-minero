# sprint nuevo minero · Repositorio de práctica

Repositorio central del taller **Fundamentos de Git** (Consorcio Minero Horizonte).
Cada pareja trabaja aquí las tarjetas del backlog y comparte sus cambios con commit, push y pull.

> Todo el contenido es ficticio. No subas datos reales ni credenciales.

## Cómo empezar
1. Clona el repositorio: `git clone <URL del repositorio en GitHub>`
2. Entra a la carpeta: `cd sprint-minero`
3. Antes de empezar cada tarjeta: `git pull`
